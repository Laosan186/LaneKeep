# 按程序分流：让某一个软件单独走代理

[English](per-app-proxy.en.md) · [返回 README](../README.md) · [防泄漏说明](leak-protection.md)

> 一句话：**路由器分不清是电脑上哪个程序在上网**，所以“按程序分流”要在电脑或手机上设置。LaneKeep 提供“专用入口”，让你指定的那个程序单独走代理，其他程序不受影响。

## 为什么路由器做不到

路由器就像小区门卫，只看得到“这份快递是 3 号楼 201 寄出的”（也就是设备的 IP 地址），看不到是屋里哪个人寄的（也就是哪个程序）。

所以 LaneKeep 的分流单位是“设备”：一台设备放进哪个模式，它上面所有程序都按这个模式的规则走。

想让“同一台电脑上，只有某一个程序走代理”，就得在电脑上告诉这个程序：“你走路由器的专用入口”。

## 先在 LaneKeep 里开一个专用入口

1. 确认这台电脑已经放进 **全局、增强或按需代理** 模式（在“设备”页分组）。常规和直连模式不能使用专用入口。
2. 打开“规则”页，切到这台电脑所在的模式，找到“专用入口”卡片，点 **新增端口**。
3. 选好出口：代理（默认节点）、指定节点或直连。
4. 点页面底部 **检查改动**，确认应用。
5. 记下两样东西，后面要填：
   - **地址**：路由器的局域网地址，例如 `10.0.0.1`（以你自己路由器的为准）
   - **端口**：刚才分配的端口，在 `10811`–`10860` 之间

## 做法一：只让 Chrome 或 Edge 走代理（最简单）

LaneKeep 自带这个功能，不用装别的软件。

1. 应用完成后刷新规则页，在端口那一行点 Chrome 或 Edge 后面的 **启用**，下载一个 `.reg` 文件。
2. 在要使用的 Windows 电脑上双击这个文件，提示时选“是”（需要管理员权限）。
3. **完全退出**浏览器（包括屏幕右下角托盘里的图标），再重新打开。
4. 浏览器设置里出现“由你的组织管理”是正常的。

关闭方法：在同一行点 **关闭**，下载关闭文件，双击运行，再完全退出并重开浏览器。

## 做法二：软件自己有代理设置

很多软件在设置里有“代理 / Proxy / 连接类型”之类的选项。通用填法如下：

| 项目 | 填什么 |
|---|---|
| 代理类型 | **SOCKS5**（不要选 HTTP） |
| 地址 / 主机 | 路由器局域网地址，例如 `10.0.0.1` |
| 端口 | 专用入口的端口，例如 `10820` |
| 用户名 / 密码 | 留空 |
| “通过代理解析域名” / “远程 DNS” | **一定要勾选** |

以 Firefox 为例（菜单名称可能随版本变化）：设置 → 常规 → 网络设置 → 设置… → 选“手动配置代理”，在 **SOCKS 主机** 填地址和端口，选 **SOCKS v5**，并勾选 **“使用 SOCKS v5 时代理 DNS 查询”**。

> **为什么一定要勾“通过代理解析域名”？** 在全局、增强、按需模式里，路由器给设备的是“假 IP”。如果软件自己先查地址再连专用入口，拿到的是假 IP，会被专用入口拒绝，表现为“打不开”。勾选后，软件直接把网址交给专用入口，就能正常工作。

## 做法三：用电脑上的分流软件按程序名分

如果软件本身没有代理设置，可以在电脑上装一个支持“按进程 / 按程序名”写规则的代理客户端，让它把指定程序的流量转发给路由器的专用入口。规则的意思大致是：

```text
程序名是 telegram.exe   →  转发到 10.0.0.1:10820（SOCKS5，远程解析域名）
其他所有程序             →  直接连接（交给路由器按设备规则处理）
```

注意：

- 只从软件官方渠道下载。
- 这类软件如果开了“TUN / 虚拟网卡 / 系统代理”模式，会接管整台电脑的流量，和 LaneKeep 的设备规则叠在一起，出了问题很难排查。**先只给目标程序写规则，其他流量保持“直接连接”。**
- 出现上不了网时，先退出这个软件，确认电脑恢复正常，再逐条检查规则。

## 手机怎么办

- **安卓**：部分代理 App 提供“分应用代理”，可以只选某几个 App。上游填路由器地址和专用入口端口，类型选 SOCKS5，同样要打开远程解析域名。
- **iOS / iPadOS**：基本做不到。系统 Wi-Fi 里的手动代理是 HTTP 代理，而且对所有 App 生效，不能只选某个 App；LaneKeep 的专用入口是 SOCKS5。这类设备建议直接把整台设备放进合适的模式。

## 须知

- **只有同一模式里的设备能用这个端口。** 设备被移出这个模式后，端口会拒绝它。端口没有密码。
- **只支持 SOCKS5 的 TCP，不支持 UDP。** 软件里的语音、视频通话（UDP）和 WebRTC 不会走专用入口，仍按这台设备所在模式的规则处理。
- 专用入口有自己的保护（私网地址、假 IP、内部端口），不参与规则页里自定义规则的上下排序。
- **出口为代理时，断线保护同样生效：** 默认节点不可用时会阻断，不会自动改成直连。出口选“直连”的专用入口不经过节点，不受断线保护。
- **要停用或删除端口前，先把软件里的代理设置改回来**（或运行浏览器的关闭文件），否则这个软件会上不了网。

## 常见问题

**设置后软件打不开网页？** 按顺序检查：

1. 这台设备是不是在全局、增强或按需模式里？
2. 地址是不是路由器的局域网地址？端口有没有填错？
3. 类型是不是 SOCKS5？有没有勾“通过代理解析域名 / 远程 DNS”？
4. 规则页里这个端口是不是“启用”状态，改动有没有应用？

**能不能让微信直连、其他全部走代理？** 可以反过来做：把电脑放进全局模式，再新增一个出口为“直连”的专用入口，用做法三把微信转发到这个端口。也可以在全局模式里，给微信用到的域名加“直连”规则。注意：微信的语音、视频通话走 UDP，不会经过专用入口，仍按全局模式的规则处理。

**常规或直连模式为什么不能用？** 这两个模式没有专用入口。需要的话，先把设备移到全局、增强或按需模式。
