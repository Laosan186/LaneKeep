# 进阶说明

[English](notes.en.md) · [README](../README.md)

## 节点与两跳链

节点、订阅来源和两跳链用稳定 ID 关联，名称只用于显示。改名不会改变引用。设备名、主机名、节点名和订阅名原样显示；术语转换只针对固定模式和字段。

两跳链的前置与后置必须是已导入的节点记录。订阅来源不是节点，不能直接作为前置；不支持嵌套链。链不能成为全局默认节点，但可以由规则或模式选择。删除仍被引用的记录会被拒绝。

部分协议组合属于实验性功能。支持解析或能生成 Xray 配置，不等于该组合已经实测。面板要求试用确认时，请先在测试网络验证；验证结果与节点配置绑定，修改连接参数会使旧验证失效。

## 节点测试

测试只在点击时运行，由一个临时 Xray 进程在路由器本机 `127.0.0.1` 上开 SOCKS 入口，经所选节点发请求；目标主机名由节点解析，没有直连路径，也不改动正在运行的配置。

- **延迟**：经节点请求 `http://www.gstatic.com/generate_204`。第一次请求含与节点的握手，显示为“首次连接”；随后在同一条连接上再发两次，取较小值作为“延迟”。
- **回退**：服务器不保持连接、复用请求失败或 204 探测失败时，延迟改用首次请求耗时，并注明“首次请求，含握手”。
- **出口**：另起一条连接请求 `http://ipinfo.io/json`，显示出口 IP 和国家，不计入延迟。这两个第三方服务会看到节点的出口地址。
- 延迟和出口两步各有 6 秒截止时间，整次测试最长约 15 秒；两跳链先测前置、再测整条链，每步同样计时。0.1.0 记录的旧结果（测量版本 2）会提示重新测试。

## 容量与统计

当前面板最多保存 21 条节点记录，两跳链也占一条。旧统计模型最多容纳 96 个指标；删除节点不立即释放历史中仍存在的指标 ID，因此还要通过历史占用检查。协议能力文件的内部模型上限不能替代面板的实际限制。

两跳链的流量统计尚未纳入旧采样模型。没有统计值不代表没有流量，也不代表链不可连接。状态、健康检测和设备流量是不同口径，不能相互当作证明。

## 断线保护与时间

健康检测依赖默认节点的 DNS 路径。默认节点失效会关闭共享保护门控，其他代理节点的流量也可能被阻断。直连、专用代理入口和未知应用自建 DoH 的边界见[防泄漏说明](leak-protection.md)。

“未知”表示前端没有足够的新鲜门控状态，不能据此声称保护正常，也不应自动改动规则。短时失败会关闭门控；恢复需要连续成功。不是自动选择其他节点。

界面完整时间按路由器时区显示；列表使用相对时间，悬停看完整时间。内部历史存储可能采用 UTC 分桶，显示时间不因此增加第二个时区。前端更换语言只改变固定文案，不翻译用户名称。

## 导入和订阅

导入结果可指出不支持的参数名，但不应把凭据值作为错误信息返回。不能据此认为导出、浏览器网络面板、订阅缓存或系统备份已脱敏。报告问题前请检查截图和附件。

订阅刷新只更新来源缓存；差异选择、导入、设默认与应用是不同步骤。刷新成功不等于节点可连接，节点测试成功也不等于每种设备、DNS 或 WebRTC 场景都通过。

## 安装与恢复

配置可以在停用状态保存。只有单独确认启用，才创建网络规则并调整 DNS。卸载前会停用并恢复由 LaneKeep 接管的内容；若其他工具随后修改了 DNS，只恢复仍由 LaneKeep 占用的字段，保留外部修改。

运行中升级会短暂停用并重新启用；已有连接可能中断。配置升级与网络接管不是原子系统快照，建议升级前保存自己的配置备份。修改过的配置文件可能由 APK 保留，请按自己的数据保留需要处理。
